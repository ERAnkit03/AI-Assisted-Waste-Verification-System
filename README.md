# 📖 About Repository

**AI-Assisted-Waste-Verification-System** is an AI-powered waste verification and management platform designed to improve waste classification, monitoring, and sustainability workflows using modern web technologies and artificial intelligence.

The system helps users verify waste categories, manage waste reports, and streamline eco-friendly waste handling processes through an intelligent and user-friendly interface.

Built using Next.js, TypeScript, Tailwind CSS, and AI-assisted workflows, the platform demonstrates how AI can be integrated into smart environmental and sustainability applications.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/ERAnkit03/AI-Assisted-Waste-Verification-System.git
```

---

## 2️⃣ Navigate Into Project Folder

```bash
cd AI-Assisted-Waste-Verification-System
```

---

## 3️⃣ Install Dependencies

### Using Yarn

```bash
yarn install
```

### OR Using npm

```bash
npm install
```

---

## 4️⃣ Start Development Server

```bash
yarn dev
```

### OR

```bash
npm run dev
```
